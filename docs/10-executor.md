# 10. Исполнитель: команда, которая производит изменение

Агент в коробке ещё не построен: контейнер поднимается, монтирует проект только на чтение и
запускает `sleep`. Поэтому изменение производит **объявленная команда** — исполнитель, — а всё
остальное остаётся прежним: патч проходит через ворота Caesar, проверку запускает Trajan, запись
ведёт Augustus.

Смысл в том, что harness не знает, кто именно ответил: DeepSeek по API, `claude -p` по подписке
или ваш собственный скрипт. Он знает только формат ответа и что с ответом делать.

## Что объявляет коробка

Файл `profile/executor.toml` в коробке:

```toml
schema_version = 1
command = "/home/ubuntu/pantheon/bin/pantheon-executor"
model = "deepseek-flash"   # необязательно: имя для записи, не для вызова
max_seconds = 300
max_cents = 5
```

Нет файла — нет исполнителя: задача тогда должна нести свой патч, и запись так и говорит.

Бюджет задачи может **уменьшить** лимиты коробки, но не увеличить: потолок задаёт коробка.

`command` — не «модель», а обычная команда. Её можно заменить на любую другую, которая говорит
на этом протоколе.

## Запрос: что команда получает

Задача приходит JSON-объектом на stdin и одновременно лежит в `artifacts/<task>/proposal-<n>/request.json`:

```json
{
  "schema_version": 1,
  "attempt": 1,
  "task": {"id": "t-1", "goal": "…", "kind": "bugfix", "paths": ["src/**"],
           "expected": "…", "forbidden": [], "budget": {"max_cents": 5}},
  "project": {"path": "/home/ubuntu/pantheon/trajan"},
  "box": {"name": "trajan", "root": "/home/ubuntu/pantheon/boxes/trajan"},
  "limits": {"max_seconds": 300, "max_cents": 5},
  "record": {"directory": "/home/ubuntu/pantheon/boxes/trajan/artifacts/t-1/proposal-1"},
  "model": "deepseek-flash"
}
```

Команда запускается в каталоге проекта и вправе проект **читать**.

## Ответ: что команда возвращает

JSON-объект на stdout, ничего больше. Ключи:

| Ключ | Обязателен | Что значит |
|---|---|---|
| `patch` | один из двух | унифицированный диф текстом |
| `patch_file` | один из двух | путь к дифу; относительный считается от `record.directory` |
| `usage` | нет | `prompt_tokens`, `completion_tokens`, `cost_cents` — что потрачено |
| `model` | нет | имя модели, как его назвал поставщик |
| `notes` | нет | список строк, которые попадут в запись |
| `duration_ms` | нет | сколько заняло по мнению команды |
| `error` | нет | «я не смог»; это записывается как отказ, а не как пустой патч |

Неизвестный ключ — дефект протокола: ответ считается неудачным, а не «почти правильным».
Пустой ответ — тоже неудача: «ничего не вернул» не равно «изменение не нужно».

## Что harness делает с ответом

1. **Ограничивает время.** Не уложилась в `max_seconds` — процесс останавливается, попытка
   записывается как неудачная.
2. **Проверяет, что команда не писала сама.** До и после вызова снимается `git status` и `HEAD`:
   если дерево изменилось, это `unapproved-write` — изменение не применяется, задача возвращается.
   Команда предлагает, а не пишет.
3. **Проверяет цену.** Если ответ говорит про `cost_cents` больше разрешённого — изменение
   записывается, но не применяется (`over-budget`).
4. **Отдаёт патч Caesar.** Тот же контракт, те же ворота, тот же отказ по путям.
5. **Зовёт Trajan** после применения — как и раньше.

Каждый вызов оставляет каталог `artifacts/<task>/proposal-<n>/`: `request.json`, `stdout.txt`,
`stderr.txt`, `change.diff`, `proposal.json` (со статусом, ценой и токенами).

## Где видна стоимость

Критерий приёмки MVP — «стоимость задачи записана». Она записана в трёх местах:

- **событие** в `ledger/<дата>.jsonl` типа `task.executed` с полями `model`, `prompt_tokens`,
  `completion_tokens`, `cost_cents`, `seconds`;
- **запись** `dispatch-*.json`, блок `executor`, и `proposal.json`;
- **сводка** в `outbox/`, раздел `## cost`: деньги, токены, модель, время и бюджет задачи.

Три правила записи:

- **Токены не выдумываются.** Не сообщила команда — в записи стоит «tokens not reported», а не 0.
- **Деньги не выдумываются.** Нет цены — «cost not reported» (а не «бесплатно»).
- **Ноль — это число.** «Модели не было» пишется словами, а не нулём в графе стоимости.

## Эталонный адаптер

`bin/pantheon-executor` — минимальная реализация протокола поверх OpenAI-совместимого
endpoint (DeepSeek по умолчанию). Он читает задачу, кладёт в промпт объявленные пути и файлы из
них, просит один диф, вытаскивает его из ответа и печатает JSON с токенами и ценой.

Настройки — только через окружение, ключ в репозиторий не попадает:

| Переменная | Что задаёт |
|---|---|
| `PANTHEON_MODEL_KEY` или `DEEPSEEK_API_KEY` | ключ |
| `PANTHEON_MODEL_URL` | endpoint, по умолчанию `https://api.deepseek.com/chat/completions` |
| `PANTHEON_MODEL` | модель, если профиль её не назвал |
| `PANTHEON_MODEL_MAX_TOKENS` | потолок ответа, по умолчанию 4096 |
| `PANTHEON_MODEL_PRICE_IN`, `PANTHEON_MODEL_PRICE_OUT` | доллары за миллион токенов; без них цена неизвестна |

Цены для `deepseek-flash` в этом проекте уже объявлены в примерах trajan: 0,30 $ за миллион
входных и 1,20 $ за миллион выходных (пиковые, проверено 2026-11-23,
`https://api-docs.deepseek.com/quick_start/pricing`). Те же числа подходят для переменных выше.

Включение в коробке:

```bash
cp ~/pantheon/boxes/trajan/profile/executor.toml.example \
   ~/pantheon/boxes/trajan/profile/executor.toml
# в файле: command = "/home/ubuntu/pantheon/bin/pantheon-executor"
PANTHEON_MODEL_KEY=… PANTHEON_MODEL=deepseek-flash \
PANTHEON_MODEL_PRICE_IN=0.30 PANTHEON_MODEL_PRICE_OUT=1.20 \
./bin/pantheon dispatch trajan --task tasks/t-2.toml
```

## Границы, названные явно

- **Не построено:** профиль и ACL Августа внутри контейнера (Hermes), поэтому исполнитель
  живёт на машине, а не в контейнере. Это следующий шаг; протокол от этого не меняется.
- **Проверка «не писал сам» — по git.** Проект не под git — предупреждение в записи, а не тихая
  уверенность.
- **Один диф за вызов.** Нет потокового вывода, нет инструментов, нет нескольких попыток внутри
  одного вызова: повтор — это новая задача или новый запуск.
- **Команда доверенная в одном смысле:** ей можно читать проект. Писать — нельзя, и это
  проверяется, а не обещается.
- **CLI под подписку** (`claude -p`, `codex exec`) — отдельный адаптер того же протокола; тогда
  бюджет считается попытками и минутами, а в записи честно стоит «модель не наша, лимиты
  вендора». Решено после MVP, этап 3 дорожной карты.
